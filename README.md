# NoPoverty - Loan Management System

## Description
A comprehensive loan management system for handling business loans, 
education loans, credit card payments, and charity reports.

## Features
- Business Loan Applications
- Education Loan Processing
- Credit Card Payment Management
- Charity Report Generation
- User Authentication

## Technologies
- Java
- Eclipse IDE

## How to Run
1. Clone the repository
2. Open in Eclipse IDE
3. Run LoanManagementSystem.java
